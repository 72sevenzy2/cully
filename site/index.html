04 / MAKE IT YOURS

Better sessions
start here.

Install Cully and set up your agent with one command. Add your MCP server URL when you are ready for shared memory.

Installation guide ↗
Install and set up Codex · macOS / Linux
curl -fsSL https://cully.net/install.sh | sh -s -- --agent codex

Use --agent claude or --agent cursor for another agent. Pass --mcp-url URL to connect your Cully server, plus --oauth if it requires sign-in.
