THE MEMORY ENGINE

Semantic recall, powered by Mem0.

Cully uses self-hosted Mem0 to index saved decisions, lessons, and project context by meaning. Your next agent can find relevant records even when it asks in different words. PostgreSQL keeps the source records; Mem0 powers semantic search across them.
